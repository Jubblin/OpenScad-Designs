# OpenScad Designs

Parametric OpenSCAD models for 3D-printable hardware jigs, fixtures, and tools.

## Projects

| Directory | Description |
|-----------|-------------|
| [openscad/rj45-t568b-feeder](openscad/rj45-t568b-feeder/) | RJ45 T568B wire feeding jig for 8P8C modular plugs |

## Workflow

1. Open a `.scad` file in [OpenSCAD](https://openscad.org/).
2. Tune parameters in the Customizer if available.
3. Render (**F6**) and export STL for printing.

Generated mesh files (`.stl`, `.3mf`, etc.) are gitignored — export locally as needed.
